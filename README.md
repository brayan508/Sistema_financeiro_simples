# Sistema Financeiro Simples

## 📌 Sobre o Projeto

O Sistema Financeiro Simples é uma aplicação web desenvolvida para auxiliar no controle de receitas e despesas pessoais. O projeto permite registrar transações financeiras, visualizar saldos e acompanhar movimentações de forma prática e organizada.

Este projeto foi criado principalmente como uma forma de aprendizado e prática de desenvolvimento web com Node.js. Durante o desenvolvimento, estou explorando conceitos fundamentais de back-end, integração entre front-end e back-end, manipulação de banco de dados e construção de APIs.

## 🎯 Objetivos do Projeto

* Praticar o desenvolvimento com Node.js.
* Aprender a criar e consumir APIs REST.
* Trabalhar com banco de dados MySQL.
* Desenvolver habilidades em JavaScript tanto no front-end quanto no back-end.
* Aplicar conceitos de organização de código e boas práticas de programação.
* Construir projetos reais para compor meu portfólio como futuro desenvolvedor.

## 🚀 Funcionalidades

* Cadastro de receitas.
* Cadastro de despesas.
* Visualização do saldo total.
* Histórico de transações.
* Exclusão de transações.
* Interface simples e intuitiva.

## ⚙️ Como Executar o Projeto

### 1. Clone o repositório

```bash
git clone https://github.com/brayan508/Sistema_financeiro_simples.git
```

### 2. Entre na pasta do projeto

```bash
cd Sistema_financeiro_simples
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Configure o banco de dados

Crie um banco MySQL e ajuste as configurações de conexão conforme necessário.

### 5. Execute o servidor

```bash
npm start
```

ou

```bash
node app.js
```

### 6. Acesse no navegador

```text
http://localhost:3000
```
